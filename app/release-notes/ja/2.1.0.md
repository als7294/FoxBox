# 自分のスタイルで演奏しよう
- LOOP: メロディモード。メロディを選ぶとビートに合わせてループ。右手を上げると明るく、左手で高く、拳でカット。S で PLUCK · FLOW · LOOP を切り替え。
- ループストリップ: ステージの下にメロディのノートを表示。マウスを重ねてドラッグ。何をしてもキーは外れません。
- フレーム: フレームをホールドすると直前の4拍がループ。広げると強く、離すと停止。新しいフレームごとに次のエフェクトへ。
- 演奏方法: 指は指を曲げて弾き、手のひらは開いた手で空中をタップ、片手はどちらの手でもすべてを演奏。どれが優れているということはありません。設定 → 演奏 でいつでも切り替えられます。
- 弾きやすく: 指を少し曲げるだけで音が鳴ります。敏感すぎる？ 設定 → 演奏 → Pluck sensitivity。
- MIDI出力: どのDAWやシンセでも「FoxBox」ポートを選択。弾いた音はノートに、手の動きはCCになります。
- FoxBox for Ableton Live: 手の動きをそのトラックに演奏するデバイス。マッピングできる4つのマクロ付き。設定 → MIDI & Ableton。
- Ableton Link: Liveや他のLinkアプリとテンポを同期。LOOP、フレーム、REMIXが追従します。設定 → MIDI & Ableton と Live の両方でオンに。
- MIDIテイク: 各テイクに.midも保存され、そのままDAWにドラッグできます。
- 光の弦: SAUCEとREMIXの弦を描き直しました。
- セットアップ: 新規インストール時に5つの簡単な質問：言語、顔を隠す、メインの手、演奏方法、音楽の場所。
- 言語: Españolに加え、ベータ版で Português、Français、Deutsch、日本語 に対応。Macの言語に従います。設定 → 演奏 → 言語 で変更できます。
