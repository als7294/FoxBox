# Joue à ta façon
- LOOP : le mode mélodie. Choisis une mélodie et elle boucle sur le temps. Main droite levée pour éclaircir, la gauche pour monter, un poing la coupe. S passe de PLUCK à FLOW à LOOP.
- Le bandeau du loop : les notes de ta mélodie sous la scène. Survole-le pour les glisser ; quoi que tu fasses, ça reste juste.
- Cadres : tiens un cadre et les 4 derniers temps bouclent. Écarte pour plus, lâche pour arrêter. Chaque nouveau cadre est l’effet suivant.
- Ton jeu : DOIGT joue avec un doigt plié, PAUME frappe l’air la main ouverte, UNE MAIN joue tout avec n’importe quelle main. Aucun style n’est meilleur ; change quand tu veux dans Réglages → Jouer.
- Jeu plus facile : un doigt moins plié suffit pour jouer une note. Trop facile ? Réglages → Jouer → Pluck sensitivity.
- Sortie MIDI : choisis le port « FoxBox » dans n’importe quelle DAW ou synthé. Les notes partent de tes doigts, les CC de tes mains.
- FoxBox for Ableton Live : un device qui joue tes mains dans sa piste, avec quatre macros à assigner. Réglages → MIDI & Ableton.
- Ableton Link : le tempo synchronisé avec Live et les autres apps Link ; LOOP, les cadres et REMIX le suivent. Active-le dans Réglages → MIDI & Ableton, et dans Live.
- Prises MIDI : chaque prise enregistre aussi un .mid à glisser dans ta DAW.
- Cordes de lumière : les cordes de SAUCE et de REMIX, redessinées.
- Configuration : les nouvelles installations commencent par cinq questions rapides : langue, visage caché, main principale, ton jeu et ta musique.
- Langues : FoxBox parle Español et, en bêta, Português, Français, Deutsch et 日本語. Il suit la langue de ton Mac ; change-la dans Réglages → Jouer → Langue.
