## 2. `RenderOutput.dry`: what "level-matched" means (clarification)
The dry buffer is placed on the same plan as the wet (onset, chunks, stretch, Beat-Lock, stutter) and mastered the
same way:
- CLUB / CUSTOM: the same loudness target and true-peak ceiling.
- BAKE: peaks at the same −6 dBFS.

The exported `dry` variant is therefore delivery-safe. **Proposal:** say so in the model docstring.

## 3. `tail_s`: ruled (integration i1) and implemented
`tail_s` is the end of the last word on the output timeline (the rekordbox memory cue "VOICE OUT"):
- It uses word timings when the source has them, else the last segment's end.
- It is clamped to the file length, and is None only when there is no speech.
- It does not depend on `tail_beats`.

## 4. Preset hints: resolved by v0.1
The server now applies `arrange_hint`/`master_hint`. `fvwks_fx.api.apply_hints()` remains for the CLI and the
audition pack.

## 5. Analyze STACK sources (for S3; now optional)
STACK voices reuse a cached Harvest analysis when one exists. If the server calls `fx.analyze()` on stack sources
after synthesizing them, the first render of a line skips a DIO analysis (about 0.2 s per voice, run in parallel).

## 6. Preview loudness numbers (clarification)
Preview `RenderOutput.loudness` is measured at the 24 kHz rack rate before the final resample, within about 0.1 dB
of the delivered 44.1 kHz file. Finals are measured on the delivered buffer.

## 7. S3 tests vs the real engine: resolved
The coordinator's d1f0b8e and S3's 2db85a7 made S3's tests engine-agnostic: engine names, real stems, VOICE OUT.

## 8. Rack descriptor (runtime data, FYI for S4 and the coordinator)
`contracts/rack.v0.json` was regenerated from this rack during integration i1. Changes relative to the v0 stub:
- `edit` has `available=True` (stutter, tape-stop and squelch are implemented).
- New params: `space.reverb_type` (plate/hall/room, advanced) and `tone.resonance` (advanced).
- New options:
  - `drive.mode`: `tube>hard`
  - `machine.vocoder_chord`: `key`
  - `edit.stutter_div`: `1/8`
- Macro targets are clamped to the rack ranges. A min below the range floor creates a dead zone: RAW's GRIT and
  SPACE only come in above 0.5.

## 9. v0.1 word timings (implemented)
- Throws feed exactly the words with `throw=True`. When a segment has no `words`, the whole flagged segment is
  thrown. The same fallback applies when a flagged segment has `words` but none of them is flagged
  (inconsistent input), so a `*throw*` is never silently lost.
- Output `segments[].words` are mapped onto the output timeline through pre-roll, stutter, R3 stretch and
  Beat-Lock. S4 can draw word ticks straight from `RenderInfo.segments`.

## 10. `RenderInfo.motion`: per-preset voice-core movement (approved by the user 2026-09-27; fx side implemented)
Most motion drivers are already in `RenderInfo` (`resolved_chain`, segments / words / throw flags, `bpm`, `bars`,
`first_word_s`, `tail_s`, peaks) and the app's own band analysis of the audio. Three things the UI can't derive
cleanly, all cheap in fx (< 5 ms, a few KB per render):
```python
class MotionEvent(Model):
    t: float          # output-timeline seconds
    dur: float
    kind: Literal["beat_lock", "stutter", "tape_stop", "swell", "throw_echo", "squelch"]

class Motion(Model):
    fps: int = 50
    events: list[MotionEvent]   # exact, from the arrange plan (e.g. the tape-stop start isn't exposed today)
    returns: str                # base64 uint8 envelope of the SPACE returns (reverb + delay + throws): tails, halos
    f0: str                     # base64 uint8, semitones above key root - 24 (0 = unvoiced), from MASK's WORLD f0

RenderInfo.motion: Motion | None = None   # v0.4, optional
```
Until then the UI approximates: events from `resolved_chain` (`edit.stutter_*`, `edit.tape_stop_beats`,
`space.swell_beats`, `space.delay_div`) with `first_word_s` / `tail_s` / `bpm`; returns as the energy after `tail_s`;
pitch steadiness from `mask.pitch_mode` / `mask.monotone` / `machine.vocoder_mode`.
- fx computes it (`fvwks_fx/motion.py`, ~2.5 ms per final render, ~2.5 KB) and attaches it as soon as
  `RenderOutput` has a `motion` field; it uses `fvwks_contracts.models.Motion` when that model exists. Tracks:
  `returns` = SPACE returns re the loudest frame of the mix, -60..0 dB as 0..255; `f0` = MIDI x 2 (0 = unvoiced), from
  MASK's pitch after breath and gate (a full whisper like GHOST is all 0). `throw_echo` events stop at -30 dB.
