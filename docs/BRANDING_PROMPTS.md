# FoxBox 2.0 branding art: prompts for GPT Image

The user's reference is a painterly anime fox in a sunlit pink and orange autumn forest. It's a **mood reference only**: every image below is an original fox and scene, never a copy.

**Scope (user):** banner + install window, launch screen + WHAT'S NEW, app icon. The playing UI stays the dark glass design. The geometric fox mark stays the logo.

**How to run them:**
1. Generate **#1 (hero)** first.
2. For #2–#5, attach the #1 image and add: "Use the same fox character as in the attached image."
3. Download each at the highest quality (PNG) and give the files to the PM.

**Style block** (already inside each prompt):
> Style: soft painterly anime illustration with clean cel shading and gentle gradients; warm backlit golden-hour sunlight filtering through a misty autumn forest; palette of peach, coral, rose pink, amber and cream with a few deep red accents; tall pale tree trunks; drifting red and orange leaves; soft bokeh and light haze; calm, dreamy, spiritual mood. Original character: a slender red fox with a cream-white chest and muzzle, white-tipped bushy tail, dark brown "socks" on its legs, tall ears with dark inner edges. No text, no letters, no logo, no watermark, no signature, no border.
